# Local Voice Bridge 拡張機能の導入・更新

この拡張機能は現在Chrome Web Storeでは配布していないため、Chrome / Braveの「パッケージ化されていない拡張機能」として導入します。通常版Chromeでは、Web Store外の任意CRXを恒久的に自動導入する方法は提供されていません。

## 初回導入

1. Windows Local Voice小窓の初回オンボーディングで`拡張機能の導入手順`を開きます。
2. Chromeでは `chrome://extensions`、Braveでは `brave://extensions` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. このリポジトリの `extension` フォルダを選択します。
6. 開いているchatgpt.comのタブが自動で接続されることを確認します。タブの再読み込みは不要です。
7. Windows小窓へ戻り、接続後に`テスト音声`を実行します。成功すると初回オンボーディングが完了します。

Local Voice小窓のタブ数が実際に開いているChatGPTタブ数へ変わり、テスト音声が成功すれば導入確認は完了です。

## 設定の役割

日常操作とWindows/runtime設定の入口はWindows Local Voice小窓です。

- `キャラクター`（内部キー`referenceVoice`）
- `音量`
- `マイク会話`
- `自動読み上げ`
- `次へ`
- `再生成`
- `停止`
- `もう一度`
- `詳細設定`

`自動読み上げ`と`マイク会話`は独立した設定です。一方のオン・オフで他方を変更しません。

Windows小窓の`詳細設定`では、STTモデル、送信前猶予、Live TTSプロファイルをLocal APIの永続設定へ保存します。拡張機能Optionsはこれらのruntime設定を所有しません。

拡張機能Optionsが直接所有するのはブラウザ固有の読み上げ範囲だけです。

- 最大行数 `previewMaxLines`
- 最大文字数 `previewMaxChars`

通常はWindows詳細設定の`ブラウザの読み上げ範囲設定`からOptionsへ移動します。Chrome / Braveの拡張機能アイコンを右クリックして`オプション`を開くこともできます。

## リポジトリ更新後

拡張機能のソースが更新されても、すでに読み込まれている拡張機能は自動更新されません。ただし、**拡張機能の切断**と**接続済み拡張機能の更新待ち**は別状態です。

### 接続済みで更新反映が必要な場合

小窓が接続済み拡張機能について更新待ちを検出し、自己reload対応も確認できた場合だけ次を行います。

1. Windows Local Voice小窓の`拡張機能を再読み込み`を押します。
2. 開いているchatgpt.comのタブは触らず、小窓のタブ数が自動で復元するまで待ちます。
3. loaded versionとexpected versionが一致し、再接続したことを確認します。
4. 接続済み旧版が自己再読み込み非対応と明示した場合だけ、Chromeでは`chrome://extensions`、Braveでは`brave://extensions`を開き、Local Voice Bridgeのカードにある再読み込みボタンを押します。これはフォールバック手順です。

### 拡張機能が切断中の場合

切断中は`拡張機能を再読み込み`を成功導線として扱いません。小窓は切断状態を表示し、自己reloadが完了したかのような表示を出しません。

1. 拡張機能が導入済み・有効であることを確認します。
2. 必要なら上の初回導入手順で`extension`フォルダを読み込み直します。
3. 小窓が再接続を検出するまで待ちます。
4. 接続後、更新待ちが別途表示された場合だけ正式なreload経路を使います。

ChatGPTタブ自体の再読み込みは通常不要です。

## フォルダを移動した場合

元の拡張機能を一度削除し、移動後の `extension` フォルダを選び直してください。拡張機能IDが変わる場合があるため、古い登録を残したまま二重導入しないでください。
